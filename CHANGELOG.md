## 🔐 Security Notes

The application is intended for educational use only.

- OTP verification is simulated locally.
- No actual SMS messages are sent.
- No real banking authentication is performed.
- No banking database is connected.
- No financial transactions are processed.
- The generated passbook is displayed in the terminal.
- Users should avoid entering real sensitive banking information.
